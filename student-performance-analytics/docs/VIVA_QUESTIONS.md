# Viva Questions & Answers

**Q1: What is Pandas used for in this project?**
A1: Pandas is used for loading the CSV file, data manipulation, cleaning, and filtering the tabular data into DataFrames.

**Q2: What is the difference between Matplotlib and Seaborn?**
A2: Matplotlib is a low-level, general-purpose plotting library. Seaborn is built on top of Matplotlib and is designed specifically for statistical data visualization, providing better default aesthetics and easier plotting of complex relationships (like pair plots or violin plots).

**Q3: How are missing values handled in this dashboard?**
A3: The dashboard detects and flags missing values. We explicitly chose not to impute (guess) missing marks because academic data should remain accurate.

**Q4: What is skewness and kurtosis?**
A4: Skewness measures the asymmetry of the data distribution around its mean. Kurtosis measures the "tailedness" (how heavy the tails are compared to a normal distribution).

**Q5: Why use Streamlit instead of Flask or Django?**
A5: Streamlit is designed specifically for data science and machine learning applications, allowing rapid development of interactive web dashboards directly in Python without writing HTML/JS/CSS.
